> **Описание проекта:**
Команда разработчиков рекомендательных систем создала новый алгоритм рекомендаций, который, по их мнению, будет показывать более интересный контент для каждого пользователя. Необходимо рассчитать параметры A/B-теста, который позволит проверить эту гипотезу, и проанализировать его результаты.

**Цель:** Рассчитать параметры A/B-теста, для проверки гипотезы.
**Задачи:** Рассчитать параметры A/B-теста, оценить корректность его проведения и проанализировать результаты эксперимента

- Произведена работа с историческими данными (EDA): загрузка, знакомство с данными, анализ числа регистраций, анализ числа просмотренных страниц
- Подготовка к тесту: сформулированы гипотезы, определена целевая метрика, размер выборки, длительность теста
- Произведен мониторинг А/В-теста
- Проанализированы результаты А/В-теста, проверена корректность результатов теста.

*Стек:* python (pandas, matplotlib, statsmodels, scipy, math)
