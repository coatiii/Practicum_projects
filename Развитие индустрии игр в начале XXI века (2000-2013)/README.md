# Развитие индустрии игр в начале XXI века (2000-2013)

> **Описание проекта:**
Изучение развития игровой индустрии с 2000 по 2013 год для написания статьи в IT-журнал.
Работа с историческими данными, собранными из открытых источников. Использован датасет, содержащий информацию о продажах игр разных жанров и платформ, а также пользовательские и экспертные оценки игр.

**Цель:** Изучение развития игровой индустрии с 2000 по 2013 год, в рамках подготовки статьи командой «Секреты Темнолесья».
**Задачи:** Познакомиться с данными, проверить их корректность и провести предобработку, получив необходимый срез данных.

- Проводилась загрузка и предобработка данных, фильтрация и категоризация по оценкам пользователей.

*Стек:* python (pandas, matplotlib, seaborn, phik)
