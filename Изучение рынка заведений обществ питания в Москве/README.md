# Изучение рынка заведений обществ питания в Москве

> **Описание проекта:**
Изучение развития игровой индустрии с 2000 по 2013 год для написания статьи в IT-журнал.
Работа с историческими данными, собранными из открытых источников. Использован датасет, содержащий информацию о продажах игр разных жанров и платформ, а также пользовательские и экспертные оценки игр.

**Цель:** Провести исследовательский анализ данных рынка общественног питания Москвы, помочь инвесторам из фонда Shut Up and Take My Money выбрать наиболее подходящее место для стартапа.
**Задачи:** Познакомиться с данными, проверить их корректность и провести предобработку, провести исследовательский анализ данных.

Было выяснено: 
- категории заведений и их количество
- какие административные районы Москвы, представленны в данных
- какое распределение категорий заведений в Центральном а.о.
- каких заведений больше: сетевых или несетевых
- количество посадочных мест в каждой категории заведения
- наиболее популярные категории в топ-15 заведений
- различия усредненных рейтингов для разных типов общепита

*Стек:* python (pandas, matplotlib, seaborn, phik)
