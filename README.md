# Проекты Яндекс практикум. Аналитика данных.
В данной папке представлены основыне проекты по:
- предобработке данных в Python (Развитии индустрии игр в начале XXI века)
- исследовательскому анализу данных (Изучение рынка заведений общественного питания Москвы, исследование стартапов)
- статистическому анализу (Исследование гипотез в бизнесе)
- А/В тестированию (Исследование А/В тестирования нового алгоритма рекомендаций в развлекательном приложении)
